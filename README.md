# Battle Factory Companion

An offline Pokémon Emerald Battle Factory companion for phone use.

## Current version

**v0.1.0 — App foundation**

The first working Expo/React Native screen includes:

- Open Level / Level 50 selection
- Current round entry
- Three draft Pokémon entry slots
- Quick Pokémon test buttons
- Scientist notes
- Initial analysis workspace
- Planned areas for complete sets, speed comparisons, and damage calculations

## Roadmap

1. Add the complete Pokémon Emerald Battle Factory data locally.
2. Add Pokémon search with names and sprites.
3. Add all Factory sets and set-by-set viewing.
4. Add speed comparison summaries.
5. Add the Emerald damage calculator.
6. Add draft matchup analysis and likely next-round threats.
7. Add battle-state tracking and theory-crafting tools.
8. Package the app for offline phone use.

## Running locally

This is an Expo app. Install dependencies, then run `npm start` and open it with Expo Go or an emulator.
